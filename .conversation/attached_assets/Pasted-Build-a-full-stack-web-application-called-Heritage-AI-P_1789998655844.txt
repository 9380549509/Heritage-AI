Build a full-stack web application called "Heritage AI".

PURPOSE:
Create an AI-powered monument recognition system for Karnataka tourism.

USER FLOW:
1. User opens the website.
2. User uploads a photograph of a monument.
3. The app shows an image preview.
4. User clicks "Identify Monument".
5. The image is sent to a backend.
6. Use Google Gemini multimodal vision to identify the monument.
7. Display the monument name, confidence score, historical information,
   architecture, interesting facts, best time to visit, and nearby attractions.

TARGET HERITAGE SITES:
- Badami Cave Temples
- Pattadakal
- Aihole
- Mahakuta
- Banashankari
- Kudalasangama
- Other Karnataka heritage monuments

AI RESPONSE FORMAT:

{
  "monument_name": "",
  "confidence": 0,
  "location": "",
  "historical_period": "",
  "historical_significance": "",
  "architecture": "",
  "interesting_facts": [],
  "best_time_to_visit": "",
  "nearby_attractions": [],
  "description": "",
  "reason_for_identification": ""
}

If the image is unclear or does not appear to be a supported
heritage monument, do not confidently guess. Return "Unknown"
and explain that a clearer image is needed.

UI:
Create a premium Karnataka heritage/tourism design.

Use:

- dark brown background
- gold accents
- modern cards
- smooth animations
- responsive mobile design
- clean typography
